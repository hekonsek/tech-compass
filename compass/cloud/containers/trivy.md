# Trivy

Status: 🟡

Trivy is an excellent open source infrastructure security scanner from Aqua Security. It can be used to scan container images, secrets, licenses, SBOM, IaC and many more. We recommend using Trivy as the default scanner before implementing other solutions.

In 2026 Trivy was affected by sophisticated attack compromising its release infrastucture. While we still recommend using Trivy, we move it to yellow status until Trivy proves that it improved its infrastructure resiliency from future attacks.
