# Ollama

Status: 🟢

Ollama is a tool that lets you download and run large language models (LLMs) locally on your own computer, rather than sending every request to a cloud AI service. For example, after installing Ollama, you can run models such as Llama, Gemma, Qwen, or DeepSeek-style models from your terminal.

Ollama CLI/server is heavily inspired by Docker design, so its user experiecne is very familar to most developers. It can be also used together with most of popular agentic coding harness frameworks (Codex, Claude Code, OpenCode, etc).

Ollama is a great tool to provide local, private LLM inference service. It is a great choice when looking for developer tooling, LLM usage cost optimization or private LLM inference infrastructure.

With over 180 GitHub stars and wide industry adoption we give it well deserved green status.
