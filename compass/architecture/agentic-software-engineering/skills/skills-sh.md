# skills.sh

Status: 🟡

While agentic skills is already an established way of modelling the behavior of your agents, there is no standard way of managing skills themselves. One of the promising attempt to standardize skills management is Vercel's [skills.sh](http://skills.sh) project.

Skills.sh provides an easy way to install and manage GitHub/GitLab skills. It supports all popular agentic frameworks and comes with skills marketplace/finder. 

We cannot give skills.sh green status because it is still emerging technology. Having said that with over 30000 GitHub stars, skills.sh is becoming one of the strongest contender in a skills management space. Skills.sh is also used by the most popular skills repositories (for example [Addy Osmani skills](https://github.com/addyosmani)). We recommend considering adoption.
