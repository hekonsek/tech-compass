# Superpowers

Status: 🟡

Superpowers is a SDD framework for coding agents. It adds a structured engineering process around an AI coding agent instead of simply telling the agent to *"implement this feature"*.

SDD frameworks are emerging technologies, hence yellow light status for it. Having said that Superpowers is the most popular SDD framework out there, with over 270.000 GitHub stars. If one would like to make a safe bet on SDD framework, Superpowers might be the safest bet.

Superpowers comes as an agent skill that can be simply added to your agent to take advantage of it. Superpowers provides value added straight after adding it to your agentic skill set, without an extra learning curve.
