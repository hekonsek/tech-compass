# Skills

Status: 🟢

Agent Skills are reusable capabilities or instructions that help an AI agent to perform particular kinds of tasks reliabily. Skills were initially introduced by Anthropic, but received wide adoption fast and evolved into [open standard](http://skills.md) adopted by all AI vendors.

Despite rapid grownth, Skills seems to be working and stable technology at this point of time. We recommend using Skills as a primary way of altering AI agents behavior at scale.
