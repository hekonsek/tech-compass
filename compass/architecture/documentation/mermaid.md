# Mermaid

Status: 🟡

Mermaid is a JavaScript-based diagram-as-code tool rendering SVG and PNG diagrams from text. 

We give Mermaid a yellow light due to lack of general standardization in the diagramming space. However if we would suggest to use one diagramming tool in your project or organization, we most like would recommend Mermaid. Mermaid with over 90000 GitHub stars and official native Markdown  support in GitHub is very close to become a winner in the space.

We highly recommend using diagram-as-code tools for diagrams, especially as these are very AI-friendly. Mermaid diagram textual representation is not only AI-friendly, but also tools like ChatGPT or Claude can render Mermaid diagrams natively.
